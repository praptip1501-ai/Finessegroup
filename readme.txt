== Description ==

Workstation is a WordPress theme for blogs, editorial sites, and content-focused publications. It includes responsive layouts, block editor styling, post metadata, featured images, and translation-ready text.

== Installation ==

1. Upload the `workstation` folder to the `/wp-content/themes/` directory.
2. Activate the theme through the WordPress admin dashboard.
3. Customize the theme using the Customizer and Site Editor options available in your installation.

== Frequently Asked Questions ==

= Is the theme translation ready? =

Yes. The theme uses the `workstation` text domain and includes a `languages` directory.

= Does the theme support the block editor? =

Yes. The theme includes block editor styling and a `theme.json` configuration.
